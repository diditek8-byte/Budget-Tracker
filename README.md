# Budget-Tracker
A simple budget management program

Features
- Add income and expenses
- Calculate total expenses
- Display remaining budget
- Edit existing expenses
- Create new expense categories
- Delete expense categories
- Save budget data using JSON

Requirement
- Python3

How to use
1. Download or clone this repository
2. Open the project folder in your terminal
3. Type: python3 main.py
4. Follow the instructions displayed in the terminal

Commands & Instructions
When starting the program, you will be prompted to enter your basic financial information.
Afterwards you have to run the program again and it will display your budget overview and asks whether you want to do anything else.
You can either type no to end the program or you can command it based on your needs.

Available actions:
- change expense
- add expense
- delete expense

When finished with either command you can press the return key twice and it will exit the program.

Choosing an expense category
When changing an existing expense, select the category you want to modify.

Available categories:
- income
- rent
- electricity
- gas
- water
- internet
- grocery
- credit
- commuting

Enter the corresponding when prompted.
